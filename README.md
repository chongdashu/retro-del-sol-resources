# Retro del Sol: prompts, models and lessons

Retro del Sol is a small coastal world for the browser. You play a courier who
walks the promenade, rides a postal trike and sails between islands to deliver
parcels. Every 3D model in it came from Retro Diffusion 3D, and coding agents
wrote and tested the game from plain-language prompts.

Play it at [retrodelsol.com](https://retrodelsol.com/) or on
[Wavedash](https://wavedash.com/games/retro-del-sol).

## What's here

The game's source code, development records and full build journey are shared
with [VibeGameDev](https://www.vibegamedev.com/) members.
